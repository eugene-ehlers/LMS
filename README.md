# LMS

Post-origination loan management for South African white-label credit providers. Identity, organisations, memberships, mandates, and product enrolment come from Enigma.

`docs/LOCKED_DECISIONS.md` is the source of truth. The Enigma port design is [docs/enigma/lms-enigma-interface.md](docs/enigma/lms-enigma-interface.md). The draft Layer 1 checklist is [docs/enigma/LAYER1_IMPLEMENTATION_CHECKLIST.md](docs/enigma/LAYER1_IMPLEMENTATION_CHECKLIST.md).

`src/lms/enigma/` is a draft sketch, not production code. HTTP paths stay unbound until `eugene-ehlers/enigma` can be read.

# LMS

Post-origination loan management for South African credit providers. Identity, organisations, and mandates stay in Enigma. This service books agreements, takes payments, and issues statements.

The servicing rules are in [docs/servicing/primary-flows.md](docs/servicing/primary-flows.md). The API contracts, state machine, and call sequences are in [docs/servicing/implementation-design.md](docs/servicing/implementation-design.md).

# LMS

Post-origination loan management for South African white-label credit providers. Identity, organisations, memberships, mandates, and product enrolment come from Enigma.

The consumer port is specified in [docs/enigma/lms-enigma-interface.md](docs/enigma/lms-enigma-interface.md). The wire format stays unbound until `eugene-ehlers/enigma` (`STATUS.md`, then `consumer_contract.py`) has been read.

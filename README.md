# LMS

Post-origination loan management service for South African credit providers. Multi-tenant, white-label. Identity, organisations, memberships, enrolment and mandates are owned by Enigma. This service keeps the account, the balances and the ledger.

Locked behaviour is [docs/LOCKED_DECISIONS.md](docs/LOCKED_DECISIONS.md). The ledger structures that follow it are [docs/account-balance-transaction-model.md](docs/account-balance-transaction-model.md). A draft Layer 1 checklist, which is not a lock and not production code, is [docs/ledger-implementation-checklist.md](docs/ledger-implementation-checklist.md).
